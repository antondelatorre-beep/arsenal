ARSENAL RUSH - deploy on Render
1. Upload these files to a GitHub repo (all in the repo root, no folders).
2. Render > New > Web Service > connect repo.
3. Build command: npm install     Start command: npm start
4. Open the URL. Quick Play / Create Server / Browse & Join by 4-letter code.
Local test: npm install && npm start  ->  http://localhost:3000
